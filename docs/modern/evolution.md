# 现代协议演进史与 GFW 对抗代际演进 (2018-2025)

> “翻墙与反翻墙的技术博弈，本质上是密码学、协议设计与大规模网络流量特征分析之间的持续拉锯战。”

在阅读本书前期章节时，你会接触到 Shadowsocks、早期 V2Ray (VMess)、SSH Tunnel、经典 VPN 等工具。许多初学者常问：**“为什么当年好用的工具，现在动不动就被封甚至连不上？”**

要理解当下的科学上网技术，就必须理解 GFW 在 2018 到 2025 年间经历了怎样的检测范式变革，以及现代协议是如何从“对抗”走向“融入”的。

---

## 一、GFW 审查手段的四次代际飞跃

回顾历史，GFW 的检测手段经历了四个核心时代：

```
[第1代: 规则拦截] ──> [第2代: 协议特征匹配] ──> [第3代: 主动探测与机器学习] ──> [第4代: 全维行为画像与精准白名单]
   (IP/DNS/关键字)          (DPI 深度报文)           (Active Probing / 熵分析)          (TLS 指纹 / 证书链 / SNI)
```

### 1. 第一代：朴素的规则拦截（2000~2010）
* **手段**：静态 IP 黑名单、DNS 投毒污染、明文 HTTP 关键字过滤、伪造 TCP RST 复位包。
* **破局方案**：修改 Hosts、第三方加密 DNS、普通的 SSH 隧道即可轻松绕过。

### 2. 第二代：基于特征的深度报文检测 DPI（2011~2016）
* **手段**：审查设备开始具备实时拆包与重组能力。像 PPTP、L2TP、原生 OpenVPN 和 WireGuard，因为有固定握手字节头部（Magic Number），在经过骨干网时被 DPI 直接识别并切断连接。
* **破局方案**：**Shadowsocks (SS)** 横空出世。将所有数据用对称密钥加密，去除了所有明文协议头。

### 3. 第三代：高熵流量分析与主动探测（2017~2021）
* **手段**：
  * **高熵识别**：正常的互联网流量（如 TLS 握手、HTTP 请求）其实包含了大量明文或结构化头部，信息熵（Entropy）分布具有典型统计规律；而纯对称加密的 SS 数据流是一串“纯粹的随机乱码”，信息熵接近 1.0（最高混乱度）。GFW 发现：*只要看到高度随机的数据流，基本就是翻墙流量*。
  * **主动探测（Active Probing）**：当 GFW 怀疑一个境外 IP:Port 在跑翻墙服务时，会主动伪装成客户端向该服务器发送各种构造畸变的数据包。如果服务器做出了符合代理协议的回应，该端口立即被拉黑（著名的 SS 1130 事件）。
* **破局方案**：**V2Ray (VMess/VLESS) + WebSocket + TLS + Nginx 自建博客**。不再试图发明新的加密特征，而是把自己伪装成一个正常的 HTTPS 网站。

### 4. 第四代：TLS 指纹、证书透明度与全维画像（2022~至今）
* **手段**：
  * 传统自建 Nginx+TLS 伪装的破绽暴露无遗：一个小小的个人域名、刚申请的 Let's Encrypt 证书、全天 99.9% 的流量全是一个 IP 在长时间进行 WebSocket 大流量吞吐，访问真实页面的普通访客为 0。
  * GFW 开始审查 **TLS 握手特征（JA3/JA4 指纹）**、证书透明度日志（CT Log），甚至直接阻断境外未知名域名的长连接。
* **破局方案**：**VLESS + XTLS-Reality（借壳伪装）** 与 **Hysteria 2 / TUIC（基于 UDP/QUIC 伪装）**。

## 二、为什么老技术被淘汰了？（对照分析）

| 协议/技术 | 产生时代 | 淘汰/衰落原因 | 当前可用性评价 |
| :--- | :--- | :--- | :--- |
| **PPTP / L2TP** | 1999 年代 | 握手特征完全固定，无任何混淆，DPI 实时拦截 | ❌ 彻底死亡 |
| **原生 WireGuard** | 2016 年代 | 原生 UDP 协议头特征极明显，骨干网直接丢包（除非包一层混淆） | ❌ 裸跑不可用 |
| **原版 Shadowsocks** | 2012 年代 | 高熵随机密文特征被 AI 识别，抗主动探测能力弱，几小时内封端口 | ⚠️ 极易被封，淘汰 |
| **VMess + WS + TLS** | 2018 年代 | 自建域名成本高、易被证书/域名画像标记；延迟高、传输开销大 | 🟡 仍可用但臃肿过时 |
| **VLESS + Reality** | 2023 年代 | **无须域名与证书**，借壳真实大厂网站，完美免疫主动探测 | 🟢 **当下主流主力** |
| **Hysteria 2 / TUIC** | 2023 年代 | **基于 UDP/QUIC**，自研拥塞控制算法，专治恶劣弱网与跨境丢包 | 🟢 **当下高速主力** |

## 三、现代科学上网的两大主导流派

进入 2023~2025 年后，协议设计形成了清晰的分流路线：

### 流派 A：极致伪装流（以 VLESS + XTLS-Reality 为代表）
* **核心哲学**：*“最完美的伪装，不是自己造一个假货，而是直接融入真货之中。”*
* **实现方式**：借用苹果（`apple.com`）、微软（`microsoft.com`）等国际大牌网站的真实 TLS 证书。GFW 过来探测时，服务器把流量原封不动转发给苹果官网，审查系统探测到的完全是官方合规站点。
* **优势**：免申请域名、免维护证书、超强稳定性、几乎无封锁风险。

### 流派 B：协议代际跃升与暴力提速流（以 Hysteria 2 为代表）
* **核心哲学**：*“TCP 的慢启动和丢包重传是跨境传输的原罪，用现代 QUIC/UDP 打破枷锁。”*
* **实现方式**：基于 HTTP/3 底层的 QUIC 协议重写，定制专门的 Brutal 拥塞控制算法。哪怕跨海光缆丢包率高达 30%，依然能把服务器的上行带宽彻底榨干。
* **优势**：晚高峰 4K 视频秒开，弱网抗丢包极强。

## 四、下一代前沿：ECH (Encrypted ClientHello)

在过去，即使使用了最安全的 TLS 1.3，客户端在刚向服务器打招呼时，第一封请求（`ClientHello`）里的 **SNI（你要访问的主机域名，例如 `google.com`）** 依然是明文广播的，GFW 正是利用这点在握手一瞬间将你重置（RST）。

2024 年前后逐步推广的 **ECH（加密客户端问候）**，将整个 SNI 字段在客户端就完成加密。届时，中间审查者只能看到一个统一的外层公共前置域名，彻底失去了在中间层根据域名阻断 HTTPS 的能力。
